# Add Knowledge samples

Open Add knowledge, choose a type, then click Use sample. Review or edit the fields and click Save to knowledge. Voice deliberately has no sample option. Existing saved items do not show this button. Replacing a draft asks for confirmation and keeps its selected collection.

- Note: DBMS keys and normalization revision notes.
- YouTube: Introduction to Database Management Systems (DBMS), using the supplied 6Iu45VZGQDk link. No transcript is fabricated. Published captions are imported when available; otherwise paste a transcript yourself.
- Web link: SQLite foreign key documentation, with an original reading prompt.
- Chat: clearly labeled example student/tutor conversation about normalization.
- File: an actual dbms-sample-notes.txt attachment, uploaded and extracted through the usual file workflow.
- Code: SQL tables, foreign keys, example records and a JOIN.

## Presentation walkthrough

1. Save the Note, Chat and File examples.
2. Search for normalization to demonstrate related content from different types.
3. Search for Atomicity to find the sample document.
4. Open YouTube, load the example and explain how the source and available captions are stored.
5. Show the SQL example and its expected result.

Web extraction and YouTube captions need network access and depend on the source. All sample fields and the text attachment can be filled without an API key. Saving uses your existing knowledge processing and configured provider settings.
