# Convexa feature verification

See [REDESIGN_VERIFICATION.md](REDESIGN_VERIFICATION.md) for the latest test evidence and remaining integration limits. The active edition supports local knowledge capture, multiple searchable content formats, source-backed ARIA, an interactive persisted knowledge map, custom focus sessions and account-specific AI connection controls.

The application works for knowledge capture and retrieval without API keys. Live caption import, cloud transcription, neural embeddings and generated answers depend on available provider capabilities, source access and quota.
