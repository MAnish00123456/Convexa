# Convexa sample knowledge

These files are included in the Convexa ZIP to test real ingestion without downloading a second archive.

| File | Save as | Search for |
|---|---|---|
| `database-test.pdf` | Distributed Systems Material | `consistent hashing` |
| `lecture-test.docx` | Classroom Document | `update anomalies` |
| `code-test.txt` | Graph Algorithms Notes | `breadth-first search` |
| `chat-example.txt` | Paste under **Add knowledge → Chat** | `structured JSON responses` |

**YouTube:** Add a genuinely captioned educational video and leave Transcript empty. Confirm captions import, then search an exact spoken phrase. Open a timestamp and verify the playback position. Captions cannot be obtained for every video; a transcript can also be pasted manually.

**Voice:** Record audio with **Add knowledge → Voice** and confirm it plays after saving and refreshing. Enter the spoken words manually to test fallback search. With Groq or OpenAI connected, upload a new recording with its Transcript field blank, then verify actual automatic transcription.

**ARIA:** Ask about consistent hashing after uploading the PDF. Check the returned source references and verify the text exists in the original item. Configure AI connections in Settings if you want to test generated answers and meaning-based search.

**Map:** Open Knowledge map, drag a document card to a new position, connect two saved items and then reload. Both the card's position and the connection should be present after reload.

**Focus:** Set a custom 7-minute timer and verify the display changes to `07:00`.

**Settings:** Add a test API key, verify the Settings page says Saved, and confirm a second account does not see that key. Remove the key when finished.
